# tinynote

A minimalist browser extension that replaces your new tab page with a scratchpad based on the VS Code editor.

## feature
- It's dead simple
- The scratchpad is persisted and synchronised across all "new tab" 
- Support all VSCode shortcut, including multi-cursor.

## Installation

### Chrome

1. Go to [release](https://codeberg.org/TheBigRoomXXL/tinynote/releases)
2. Download "Source code (zip)"
3. Then go to the [chrome extension manager](chrome://extensions/)
4. Enable developper mode with the switch a th top right of the page
5. Click on "load unpacked extension" and select the ZIP

### Firefox

1. Go to [release](https://codeberg.org/TheBigRoomXXL/tinynote/releases)
2. Download "tinynote-X-Y.xpi
3. Accept the pop-up to install the extension


### Safari

I don't own an apple device or plan to so you are on your own 🤷.
